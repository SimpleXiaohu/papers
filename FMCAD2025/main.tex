	\begin{abstract}
			We present OSTRICH2, the latest evolution of the SMT solver
            OSTRICH for string constraints. OSTRICH2
            supports a wide range of complex functions on strings and provides
            completeness guarantees for a substantial fragment of
            string constraints, including
            the straight-line fragment and the chain-free fragment.
            %, a string‐theory extension for the Princess SMT‐solver that
            %brings advanced string reasoning capabilities to SMT‐based
            %verification and analysis.
            OSTRICH2 provides full support for the SMT-LIB theory of
            Unicode strings, extending the standard with several
            unique features not found in other solvers: among others,
            parsing of ECMAScript regular expressions (including look‐around
            assertions and capture groups) and handling of
            user‐defined string transducers.
            %Its modular architecture leverages the BRICS automata
            %library to efficiently handle automaton‐based operations.
            We empirically demonstrate that OSTRICH2 is competitive to other 
            string solvers on SMT-COMP benchmarks.
        \OMIT{
            We show by case studies and experiments that OSTRICH2 is not only capable of 
            solving string constraints involving complex
            regular expressions and transducers that lie beyond
            the reach of existing solvers, but also remains competitive on
            standard benchmarks.
        }
